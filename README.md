# 🛍️ GPTrio - Loja de Roupas e Calçados

Bem-vindo ao repositório oficial da **GPTrio**, uma loja virtual de roupas e calçados desenvolvida como projeto acadêmico. O objetivo é oferecer uma experiência moderna de compra, com uma interface simples e intuitiva, além de um sistema funcional de carrinho, categorias e integração com banco de dados.

## 🧰 Tecnologias Utilizadas

- **Frontend**:
  - HTML5
  - CSS3 (com Bootstrap 5)
  - JavaScript (puro)
- **Backend**:
  - Python 3 (Flask)
- **Banco de Dados**:
  - MySQL (hospedado externamente)
- **Hospedagem**:
  - Render (para o app Flask)
  - Aiven (para banco de dados MySQL)

## 🚀 Funcionalidades

- Visualização de produtos por categoria (Camisas, Calçados, Bermudas, Moletons)
- Sistema de carrinho com adição e remoção de itens
- Página de login/cadastro 
- Imagens dos produtos dinâmicas via banco de dados
- Responsivo para diferentes tamanhos de tela
